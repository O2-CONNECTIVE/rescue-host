# 提供段階と検証状況

[READMEへ戻る](../README.md)

対象は公開済みの v0.2.1-dev です。
この文書は既存README、[引き継ぎ](../HANDOFF_V021.md)、[公開検証ログ](../verification/unittest.txt)、[検証集計](../verification/result.json)、[公開レビュー](../SECURITY_REVIEW_V021.md)を整理したもので、新しい実環境の検証結果は含みません。
新規接続は無効で、本番利用できません。

## 二つの属性の読み方

**提供段階**は機能をどの範囲で提供するかを示します。
本表の分類は文書上の整理であり、新たなリリースや利用承認ではありません。

| 提供段階 | 定義 |
|---|---|
| 計画 | 開発目標または仕様のみ。対象機能の実体は未提供 |
| Alpha | 開発用の一部実装。制約と未完成部分があり、本番利用不可 |
| Beta | 対象用途を限定して試用提供する段階。既知の制約を明示する |
| GA | 明示した対象環境と用途で一般提供する段階 |

**検証状況**は、対象環境と確認範囲に対する証拠の有無を示します。

| 検証状況 | 定義 |
|---|---|
| 未検証 | 対象環境での動作を示す公開検証結果がない |
| 部分検証済み | モック、模擬接続、一部条件などの公開検証結果がある。対象環境全体の確認は未完了 |
| 対象環境で検証済み | 明記した環境と範囲で公開検証結果がある。他の環境や範囲への保証は含まない |

実装済みというだけでBetaやGAにはしません。
オフライン試験に成功しても、実SSH、Windowsの権限境界、確実な失効の検証へ読み替えません。
現時点でBetaまたはGAとする機能はありません。

## OSと役割ごとの範囲

実リモート接続を「対応済み」と呼べるOSはありません。
ホスト（救援されるPC）、controller（操作するPC）、開発環境を区別します。

この環境表の「未対応」は、本候補で提供しないことを示します。

| 役割・確認項目 | Windows | macOS | Linux |
|---|---|---|---|
| 救援されるPC（ホスト） | **計画／未検証**：主な想定対象。新規接続は無効 | **未対応**：ホスト対応を確立していない | **未対応**：ホスト対応を確立していない |
| 操作するPC（接続元） | **未検証**：接続元としての動作確認なし | **計画／未検証**：想定する接続元。実接続なし | **未検証**：接続元としての動作確認なし |
| Pythonのオフライン開発・試験 | **未検証** | **未検証** | **対象環境で検証済み**：Linux / Python 3.12.14のオフライン試験82件と構文検証のみ |
| Tkinter GUIの実表示・入力 | **未検証**：画面・表示倍率・キーボード等 | **未検証** | **未検証**：モック試験は実描画ではない |
| 配布物・CPUアーキテクチャ | **未検証**：x64向けビルドスクリプトのみ。EXE未生成、ARM64未検証 | **未対応**：専用配布物なし。CPU別検証なし | **未対応**：専用配布物なし。CPU別保証なし |
| ACL・保護サービス・実SSH・失効 | **未実装／未検証**：本番利用を阻む要件 | **未対応**：ホスト用の安全境界なし | **未対応**：ホスト用の安全境界なし |

Python部分の移植可能性は、各OSでの動作確認やホスト対応を意味しません。
`Python 3.11以上`はソースの想定条件であり、全OSと全Python版の試験済み宣言ではありません。
Linuxの合格はオフライン処理だけで、救援ホストとしての対応ではありません。

## 公開済みの検証結果

2026-10-26の公開記録では、Linux / Python 3.12.14でunittest 82件（うちバックエンドモデル19件）とcompileallが成功しています。
詳細は[検証集計](../verification/result.json)、[原ログ](../verification/unittest.txt)、[v0.2.1レビュー](../SECURITY_REVIEW_V021.md)を参照してください。
これは今回の文書整理で実行した新しい試験結果ではありません。

テストは模擬Uptermとモックを使い、公開中継、実PC、TCPポート22へ接続しません。
模擬ライフサイクル試験では開始ゲートと監視起動をテスト内だけで置き換えています。
GUIメソッドの試験も実画面の描画ではありません。

Windows GUI、表示倍率と入力、EXE、PowerShellビルド、実SSHと中継、ACL、保護された期限執行、スリープと再起動は未検証です。
[開発手順](development.md)と[接続再開の安全要件](security.md)も参照してください。
