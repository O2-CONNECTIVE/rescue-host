## 修正の確認

| 脅威・不具合 | 確認した挙動 |
|---|---|
| 名前のない `ended` を要求対象に補完 | 必須の `name` 一致確認で拒否。補完しない |
| 同名だが 起動ID・実行ファイル・検索環境が不明な旧終了応答 | 名前付き `ended` / 終了コード4 とも終了証明にしない。GUI、停止ワーカー・監視プロセス は記録・鍵を保持 |
| JSON配列・誤型の設定で回復開始前にクラッシュ | 制御された設定エラーにし、GUIは制限付きの既定設定で回復の予約を継続 |
| 旧 `terminal` 設定がフル操作権限に移行 | スキーマ1は接続方式と独立に制限付きへ移行。スキーマ2 の既知型・値を検証 |
| GUIイベント内のファイルエラーが以後の処理を停止 | `finally` で再予約。処理失敗時も回復記録を保持。監視プロセスの整理処理で発生する `OSError` も再試行対象 |
| 鍵の整理 失敗前に回復記録を削除 | 鍵を先に処理し、成功後に記録を削除する順序へ変更。旧記録を扱う実際の経路 では自動削除まで到達しない |
| GUIでフル操作を選ぶと開始制限を迂回 | 警告つき設定選択のみ。両モードとも GUI・ワーカー の無条件開始拒否を維持。管理者昇格は含まない |
| 停止未確認なのに画面終了が停止成功を暗示 | 専用の「画面だけ閉じる」は既定「いいえ」 の警告確認後に 画面の破棄のみ。接続継続リスクを説明し、記録・鍵を消さない |

**以前の SECURITY_REVIEW_V02.md / HANDOFF_V02.md にある「明示 ended で自動整理」の説明は過去版の記録であり、本版では上表の保守的扱いに置き換わる。** 旧記録に 起動同一性 がなかった事実を後から推定で埋めない。同名の古い応答で表示件数が変わり得る旧 GUI 仕様は残るが、それを停止証明や開始許可に使わない。

## オフラインの操作方針・期限管理の敵対的確認

- `Settings.to_operation_policy()` は検証済み設定から オフライン操作方針 に変換する明示的な橋渡しで、旧接続方式 に影響されず、開始や認可は行わない。
- 操作方針は変更禁止のデータクラスで、値は文字列と整数。モードを含むダイジェストをセッション同一性に束縛し、異なる起動ID・実行世代・方針を拒否。
- 制限付き・フル操作とも外側チャネルは `direct-tcpip`, 文字列 `127.0.0.1`、厳密な整数型の `22` のみ。シェル・コマンド実行・セッション・PTY・SFTP・逆向き転送・エージェント・X11・ローカルソケット・不明なチャネル を拒否。ホスト名、IPv6、空白、NUL、整数・16進数・省略・ゼロ埋め表記のIPv4、LAN・インターネット、別ポート・真偽値・浮動小数点・文字列のポート を許可しない。
- 両モード `allows_admin=False`。制限付きヘルパー は固定 ID と空タプル 引数だけ。任意コマンド・任意のサービス 引数を受けない。**ヘルパー実体は未実装で、実 OS の権限制限を証明したものではない。** フル操作の内側シェル 許可も設計値にすぎない。
- 準備・利用可能・有効の状態遷移順序、期限・短期リース・連番の再送拒否、時計後退/ジャンプ/読取失敗、最大期限を超える更新の拒否を確認。
- 接続処理中の要求を収容上限に計上。別スレッドで接続処理を止め、その間に失効させ、遅れて返ったチャネルを閉じる競合試験に成功。切断失敗は参照を保持して `REVOKING` のまま再試行し、`TERMINATED` から復活しない。
- 独立した追加試験でも 制限付き・フル操作の両方について NUL・非標準IPv4等の拒否、2スレッドのイベント同期による接続・失効の競合を確認した。

## 残存リスク・未検証

1. SSH公開鍵認証、実際のチャネル要求処理、固定先への接続、内側sshd・ヘルパーの制限、保護サービス/Job/ACL/認証付きIPC・起動世代 は未実装または未検証。外側転送を限定しても内側シェル の能力は限定されない。
2. モデルは呼び出し側の `poll()` と正しく実装された模擬アダプターに依存する。同期的な `close()` は再入可能ロック保持下で呼ぶため、停止すれば進行できない。例外なしで戻ることも実通信・プロセスの終了証明ではない。実装には取消・期限付き非同期終了処理、独立したリース失効とゲストから保護された監督が必要。
3. GUI終了・同一ユーザーの監視プロセス は失効の保証ではない。停止は外部で事実確認し、元の回復証拠を保管する。新GUIの「画面だけ閉じる」は接続を止めない。
4. 内側 sshd の別プロセス、既実行操作・永続化・漏洩認証情報まで 外側通信の終了で取り消せない。フル操作・管理者権限の影響範囲を別途扱う。
5. Windows実機/VM、Tk表示・表示倍率・キーボード・スクロール、PowerShellビルド、EXE、スリープ・再起動、実SSH/TCP、中継の修正適用・信頼、故障時の実時間上限は未試験。画面描画なしのGUIテストは視覚検証ではない。
6. 秘密鍵・既知トークン形式・個人ホームパスのテキストパターンスキャンに該当なし。テスト鍵/名前/トークンは固定ダミー。網羅的漏洩証明ではない。元の プレビューPNG、キャッシュ、旧検証成果物 を新成果物の検証根拠に含めない。

本レビューでは実ネットワーク/本番PC/サービス操作/認証情報を利用せず、外部公開・GitHubプッシュ も行っていない。開始ゲート解除には実バックエンド 実装と敵対的 Windows 検証、別途の接続・公開承認が必要。
