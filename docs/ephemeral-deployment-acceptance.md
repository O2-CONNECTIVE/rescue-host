# 単発版の配置に関する受入計画

[配置と責任分担](ephemeral-deployment-architecture.md) / [配布版の受入記録](windows-acceptance-records.md) / [限定評価手順](windows-evaluation-runbook.md)

運営中継コンテナと、顧客端末の同梱ネイティブ/一時非管理者guestという採用済み配置に対応する補助計画です。
全項目は未実行で、実装、評価対象、独立観測手段と操作の承認が揃うまで開始しません。
既存44条件、配布版8件のID、JSON schema、合否は変更しません。
以下の項目名を既存受入の代替IDや成功記録には使いません。
固定宛先や製品wireの改定が必要な方式は、その契約を先に確定し、別経路の成功を現契約の合格にしません。

## 開始前の確定事項

sourceと配布候補、採用するWindows実行方式、支持するSSH機能、guestの実効権限、固定されたTCP方針を確定します。
TTL、非活動の定義と閾値、短lease、論理接続喪失の検出、物理停止上限と観測起点を分けます。
中継認証、端末host keyの照合、保存metadataと保持期間、更新と再起動時の挙動を確定します。
実機操作は対象、変更前後、影響、停止と復元、回収方法を既存承認へ照合し、未知の値を仮定して実行しません。

## 観測する条件

| 対象 | 期待結果と独立観測 | 現在の状態 |
| --- | --- | --- |
| 顧客側の前提 | 選択したpackageで顧客側のcontainer runtime導入を要求せず、OS/GUI等の実前提と不足は正確に表示 | 未実行 |
| 端末の本人承認とguest分離 | 正規operatorの実message認証後だけ承認が成立。非管理者guestや中継の資格で承認/更新不可。別ログオンへ旧grant移譲なし | 未実行 |
| 中継と端末の認可分離 | 許可外鍵、誤配送、変更した接続識別子で作業が始まらず、禁止先へのdial/作用がない。中継設定で端末許可を拡張不可 | 未実行 |
| 暗号化とmetadata | 端末host key不一致を拒否。中継が遠隔秘密鍵、端末host秘密鍵、guest資格や平文作業streamを保持しない設計と実設定を照合。metadataは確定した項目/保持方針に従う | 未実行 |
| 中継の切断/再起動/削除 | 同じ論理接続の喪失を端末側が検出し旧grant失効。再登録、同じ配送ID、保存metadata、鍵所持だけで再開不可。端末processの停止は中継停止とは別観測 | 未実行 |
| 期限と故障 | 最大期限、idle、短leaseを別に観測。pollや中継keepaliveで不当に延長しない。遅い起動結果、親死、監督hang、close故障、sleep/復帰でも確定した失効/停止条件を満たす | 未実行 |
| 実行と停止所有 | 正規guestの同実token/targetを非信頼実行前に検査。許可外通信、別ログオンや外部broker起動を閉じる機構と、その支持範囲を確認。Job空だけで所有外処理終了を認定しない | 未実行 |
| 既存SSHとの共存 | 既存service、設定、鍵、DefaultShell、接続とportを変更/奪取しない。別SSHから同guestへ迂回できる構成とunknownを偽合格にしない | 未実行 |
| 二重起動/旧版/残留 | 既存sessionを奪わず、版不明、削除待ち、他所有や所有不明を上書き/一括削除しない。追加起動を閉じ、回復に必要な状態を表示 | 未実行 |
| 撤去と再起動後回復 | 削除より先に許可失効。通信終端、実processのexit/reap、Job回収、reader join、guest無効化と所有資源撤去を分けて観測。削除失敗でも旧許可を拒否し、旧grantは復元しない | 未実行 |
| GUIと所要時間 | 失効、停止受付、終了未確認、撤去結果を区別。起動と承認/guest準備/回収の時間は候補と条件を固定して測り、未合意の目標値で合格にしない | 未実行 |

試した攻撃例で問題が出なかったことだけでは、全経路の保証にはなりません。
支持する全操作を覆う強制機構と対応host条件の設計/source根拠を、同じ候補の実機観測へ結びます。
有限model、fixture、形式検査、CIはそれぞれの範囲だけの証拠です。

## 終了と記録

失効、新規/再接続拒否、通信両端の終端、reader join、process exit/reap、Job回収、資源撤去は[既存の受入記録](windows-acceptance-records.md)の区分を使います。
中継container削除や停止receiptだけで、端末の終了欄を埋めません。
本人停止、対象や権限の不一致、禁止作用、所有/観測不能、承認済み上限超過では中止し、終了未確認のまま次の利用へ進みません。
公開するのは候補、受入条件との対応、匿名の結果と不足の要約だけです。
端末識別情報、実際の資格情報、接続識別子、個別の値や生ログを本書へ入れません。
未実行、失敗、取得不能、強制回収を成功へ変更せず、結果が揃うまで新規接続gateを閉じます。
