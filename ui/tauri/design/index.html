01 / 色は意味のために

情報・主操作 警告・処理中 終了の確認 危険・確認不能

青い「接続中」は、通信状態を示す役割です。安全性の認定や操作範囲の保証を含みません。

02 / 接続と終了を区別する

すべて表示仕様の例。色が見えなくても、記号と文言で区別します。

○

↔

停止中

終了を確認しています。停止要求だけでは「終了確認済」にしません。

✓

終了確認済

所有通信の終了を確認できた場合の見本です。実行済みの変更は取り消しません。

!

終了を確認できません

終了の証拠が足りません。画面を閉じても、通信が止まった証明にはなりません。

診断情報の表示位置

詳細ログや診断はこの別領域へ分けます。この見本ではログの読取・表示機能はありません。

状態の読み方

  • 接続中と、安全に認可されていることを同じ意味にしません。
  • 停止要求 → 停止中 → 終了の観測結果、の違いを保ちます。
  • 残り時間やボタンの色は、権限・失効・終了の根拠にしません。
