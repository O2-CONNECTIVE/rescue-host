# 操作側クライアントの操作プロトタイプ

## 制作前の仕様

救援される側の既存ホスト画面とは別の、接続する担当者のためのブラウザープロトタイプです。
目的は、接続先・許可範囲・期限を読んで依頼し、承認、接続、停止要求、終了確認の違いを体験できることです。
ライトの既存 semantic tokens、所有 shadcn 部品、Lucide SVG と日本語ラベルを使います。
主領域を接続フロー、補助領域をモック応答と診断にし、停止操作を状態の近くへ置きます。

1. 固定サンプルのコードまたは接続定義を入力する。実コード・鍵・実接続定義は入力しない。
2. 架空の接続先、SSH の許可範囲、期限を確認し、チェックして承認を依頼する。
3. モックの承認応答と接続完了を別操作で進める。承認だけで接続中にしない。
4. 停止要求の受付だけでは終了確認にしない。別のモック観測で確認済み、または確認不能へ進む。
5. 期限切れ・失敗・通信喪失は終了の証明にしない。診断は固定 code とモック状態だけを示す。

全状態で「操作プロトタイプ・実接続なし」を明示します。
画面の状態は実接続や安全認証の根拠ではありません。実通信、認証・承認 API、資格情報、OS 設定、ホスト runtime、製品 gate、native 配布は非目標です。
入力はサンプルの allowlist に照合し、確定時に欄を消します。controller / adapter へ生入力を渡さず、保存・ログ・URLへ残しません。
コピーする場合も固定サンプルの確認内容だけとし、コードや接続定義は含めません。

## 検証境界

### 2026-10-28 の仕様更新

初期は1接続に限定し、接続準備後に秘密鍵・passwordを含まないサンプル接続情報をコピーして外部エージェントへ渡します。
実SSHをこのGUIから起動しません。コピーの前には接続先・許可範囲・期限を確認します。
閉じる操作のモックはトレイ格納として扱い、現在の接続状態を維持します。実トレイとOS通知は未配線です。
重要な変化だけを通知モックへ表示します。状態の再確認は同じ有効sessionのread-only要求だけで、再承認・コマンド実行を自動化しません。
失効後は元sessionへ復帰せず、新たな承認が必要です。終了確認がない間は新規接続を禁止します。
履歴削除や表示の初期化もこの禁止を解除しません。同じ接続の独立した終了確認応答は、単なる接続成功応答と区別します。
履歴の製品仕様は表示名・日時・終了結果だけのローカル保存と30日削除です。今回の実装は注入時計を使うメモリmockで、永続化と実機通知は未実装です。
履歴削除はこのmockが作る項目だけに作用し、ユーザーPCの既存データを削除しません。

controller の公開操作→表示状態と、browser の利用者操作→画面を確認します。
停止要求と確認の分離、承認と接続の分離、期限切れ、失敗、確認不能、古い応答、破棄後の応答を扱います。
keyboard、focus、名前・状態通知、診断開閉、狭幅、200%文字拡大、reduced motion / forced colors の模擬表示を確認します。
native、screen reader 実機、他 OS の WebView、WCAG AA 達成は検証済みとしません。

`src/operator` とこの入口だけを所有し、共有 workflow と package scripts、Rust / Go は変更しません。
build 出力は `operator/dist/` に分離し、ホストの `dist/` と Tauri 配布へ混ぜません。
共有 CI の接続は task-3 / 統合担当に引き継ぎます。正式 PR approve と main merge は担当外です。
